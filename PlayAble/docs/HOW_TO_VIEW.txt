HOW TO VIEW THIS DOCUMENTATION
================================

OPTION 1: Double-click index.html (Easiest)
--------------------------------------------
Simply open the file "index.html" in any web browser.
All 303 documentation pages will be accessible with full search and navigation.

OPTION 2: Use a web server (Best experience)
---------------------------------------------
For proper styling and functionality:

Using Python:
  cd to this directory
  Run: python -m http.server 8000
  Open browser to: http://localhost:8000

Using Node.js:
  cd to this directory
  Run: npx http-server -p 8000
  Open browser to: http://localhost:8000
