    • generateCsrfToken: (req: Request, res: Response) => string

      Generate CSRF Token Utility

      Generates a new CSRF token for the current request/response. Call this in your token endpoint to provide tokens to the frontend.

      Example

      router.get('/api/csrf-token', (req, res) => {
        const token = generateCsrfToken(req, res);
        res.json({ csrfToken: token });
      });
    • csrfErrorHandler: (err: any, req: Request, res: Response, next: NextFunction) => void

      CSRF Error Handler Middleware

      Provides user-friendly error messages when CSRF validation fails. This middleware should be applied AFTER the CSRF protection middleware.

      Error Scenarios:

      • Missing CSRF token
      • Invalid CSRF token
      • Expired CSRF token
      • Tampered CSRF cookie

      Security Logging: Logs all CSRF validation failures for security monitoring and incident response.

    • validateCsrfToken: (req: Request, token: string) => boolean

      CSRF Token Validation Utility

      Manually validate a CSRF token without using middleware. Useful for custom validation logic or non-standard endpoints.

      Example

      const isValid = validateCsrfToken(req, req.headers['x-csrf-token']);
      if (!isValid) {
        return res.status(403).json({ error: 'Invalid CSRF token' });
      }
