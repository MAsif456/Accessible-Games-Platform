      useGlobalKeyboardNavigation Hook

      Custom React hook for providing global keyboard navigation across the entire application. Automatically handles arrow keys, Home/End, Enter/Space, and Escape without requiring manual setup on each page. Detects navigation context (navbar, grid, menu, etc.) and applies appropriate navigation behavior.

      Features:

      • Context-aware navigation (navbar, grid, menu, toolbar, footer)
      • Automatic focusable element detection
      • Arrow key navigation with looping
      • Home/End key support
      • Enter/Space activation
      • Escape key for closing dropdowns
      • Ignores text input fields to allow normal typing

      Utility functions for finding focusable elements and navigation context

      • findFocusableElements: () => HTMLElement[]

        Finds all focusable elements currently visible in the document. Filters out hidden, disabled, and non-visible elements.

      • getNavigationContext: (
            element: HTMLElement,

        Determines the navigation context for a given element. Identifies whether the element is part of a navbar, grid, menu, toolbar, or footer. Returns context information including container and navigation direction.
